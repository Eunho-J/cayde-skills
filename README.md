# cayde-skills

글쓰기와 설계 검토를 위한 Codex 스킬 원문을 관리합니다.

- [writing-structure-guide](skills/writing-structure-guide/SKILL.md): 글의 구조 선택, 섹션과 문단 구성, 집필과 검수를 다룹니다.
- [design-persuasion](skills/design-persuasion/SKILL.md): 한국어 설계·아키텍처 의사결정을 검토하고, 후보와 승인된 결정을 구분하며 단계별로 합의를 정리합니다.

스킬 원문은 각 디렉터리의 `SKILL.md`에 있습니다.
